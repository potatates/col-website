# 官网内容管理说明（新闻发布 / 修改新闻 / 更换海报）

公众号发了新文章后，不需要再手动复制到官网。整个过程大约 5 分钟：**粘贴链接 → 预览检查 → 发布**。同一个页面还能修改已有新闻、更换作品海报。

## 日常使用：内容管理页（不需要 GitHub 账号）

打开 **https://potatates.github.io/col-website/news-admin/**（建议加入浏览器收藏），输入密码（网站负责人通过企业微信发给你）。

页面上方有三个分页：「导入与发布」「修改新闻」「更换海报」。

### 导入与发布

1. **导入**：粘贴公众号文章链接（公众号文章右上角「复制链接」；可以一次粘贴多条，每行一条），选栏目和标签，点「生成草稿」。已经导入过、或官网上已有同标题的文章会自动跳过。
2. **预览**：约 3–5 分钟后，草稿出现在「待发布的草稿」里（可点「刷新」）。点「预览」检查：
   - 标题、日期、导语（标题下面的那段话）是否合适。公众号没写摘要时，会自动用正文第一句。
   - 小标题是否识别对了；有没有多余的文字（如活动报名、二维码说明）。
   - 图片是否齐全、图注是否对。
   预览页底部有黄色「草稿预览」提示；草稿不会出现在新闻列表里，只有拿到链接的人能看到。
3. **发布**：没问题点「发布」，几分钟后出现在官网新闻列表和首页。不要这篇就点「删除草稿」。

「最近的操作」里如果出现红色「失败」，截图发给网站负责人。

### 修改新闻

选一篇新闻（已发布的和草稿都可以）和语言，改标题、日期、标签、导语、封面或正文，点「保存」，约 3–5 分钟后网站更新。

- 正文写法：段落之间空一行；`## 小标题`；`> 引语`，下一行 `> — 说话人`；`![图注](编号/1.jpg)` 是正文里的图片（整行剪切可以移动图片位置）。
- 勾选「草稿」可以把已发布的新闻撤回（不在列表显示）；取消勾选即发布。
- 选「英文版」时如果还没有英文版，填好标题、导语和正文保存，就会生成英文版。

### 更换海报

找到作品（可以搜索作品名），点「更换」，选一张新图。新图会自动按原海报的比例从中间裁好，确认后约 3–5 分钟网站更新。如果提示「新图比原来模糊」，建议换一张更清晰的图。

> 新增作品（新的 IP 卡片、标签、数据）目前还需要网站负责人在代码里加，内容管理页只能更换已有作品的海报。

## 备用方式：直接在 GitHub 上操作（需要仓库写权限）

- 导入：仓库 → **Actions** → 「导入新闻（公众号链接）」→ **Run workflow**，填链接、栏目、标签。
- 发布 / 删除：**Actions** → 「发布新闻」→ **Run workflow**，填编号，选 `publish` 或 `delete`。
- 修改草稿：打开 `src/news/<编号>/zh.md` → 铅笔图标编辑 → **Commit changes**。

## 发布页的密码和钥匙（网站负责人）

内容管理页靠一把 GitHub「钥匙」（fine-grained personal access token）替使用者运行导入、发布任务，以及保存修改和海报。钥匙用密码加密后放在 `src/data/news-key.json`，网站上没有明文。

- 设置或更换：在 GitHub 新建钥匙（只选本仓库，权限给 **Actions: Read and write** 和 **Contents: Read and write**），然后在电脑上运行 `node scripts/news-key.mjs`，粘贴钥匙、设定密码，提交并部署。
- 只是给现有钥匙加权限（例如「修改新闻」「更换海报」提示没有权限）：在 GitHub → Settings → Developer settings → Fine-grained tokens 里编辑这把钥匙，加上 **Contents: Read and write**，保存即可，钥匙和密码都不用换。
- 钥匙有有效期（最长一年）。过期后发布页会提示「钥匙已过期」，按上面步骤重新设置即可。
- 仓库迁移到公司 GitHub 账号后：改 `src/pages/news-admin.astro` 里的 `REPO` 一行，并用新账号重新设置钥匙。

## 英文版

- 如果仓库设置了 AI 密钥（Settings → Secrets and variables → Actions → `ANTHROPIC_API_KEY`），导入时会自动生成英文草稿 `en.md`，预览地址是 `/en/news/<编号>/`，**请找懂英文的同事看一遍**再发布。
- 没有密钥时不生成英文版，这篇新闻**只出现在中文站**。之后要补英文：在 `src/news/<编号>/` 里点 **Add file → Create new file**，文件名 `en.md`，把 `zh.md` 的内容复制过去翻译（`---` 之间的 `title`、`tag`、`summary` 也要翻译，其他行不动），提交即可。
- 产品名的拼音写法：XiaoYao、ZhongWen XiaoYao、CiYuan ShenBi、SiYueTian、HaiLi Stories、MiXiang、QiXiang。

## 新闻文件长什么样

每篇新闻一个文件夹 `src/news/<编号>/`，配图在 `public/news/<编号>/`。`zh.md` 示例：

```
---
date: 2026-10-16
section: official
title: "中文在线亮相戛纳电视节，FlareFlow携手Digicel拓展中南美洲市场"
tag: "海外"
image: 2026-10-16-ab12cd/cover
summary: "导语，显示在标题下方和新闻列表里"
draft: true
---
正文第一段……

## 小标题

![图注（可不写）](2026-10-16-ab12cd/1.jpg)

> 引语内容
> — 说话人 职务
```

- `draft: true` = 草稿；「发布新闻」做的事就是删掉这一行。
- 只想在新闻列表里放一个跳到外部原文的链接（不在本站发全文）：加一行 `link: https://...`，正文留空。

## 和公众号原文相比，官网上会有哪些不同

- 统一使用官网的字体和版式，公众号里的彩色字、居中、装饰线、表情包、动图不保留。
- 保留：标题、导语、封面、小标题、正文、引语、文中图片和图注。
- 自动去掉：文末的「关注我们」、二维码、「阅读原文」、往期推荐。
- 公众号视频、小程序卡片无法在官网播放，需要另外提供视频文件或外链。
- 偶尔识别不准（比如把一句很短的加粗句子当成小标题），预览时改一下即可。
